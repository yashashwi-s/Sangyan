# Fixed public guidance translation provenance

The 111 retained `guidance-*` strings and 157 revised `resilience-*` strings are committed public educational copy. The source is English. Regional versions are draft translations, initially produced at build time through the public translation endpoint used by the existing project workflow. No user record, password, identifier, complaint note or uploaded document was sent. Runtime translation is entirely local and uses only the selected static language pack.

Structural review on 4 October 2026 removed translated batch-marker fragments from the older Konkani, Dogri, Maithili, Meetei and Sanskrit guidance and new support packs. Broken English fragments inside Odia words were rewritten as complete draft Odia instructions. Two malformed Dogri passages and confusing Hindi task labels were revised. These editorial corrections do not constitute fluent-speaker or legal certification. Exact key sets, nonempty strings, encoding, markup/marker artifacts and compressed budgets are checked at build time. Meetei Mayek and Ol Chiki font glyph coverage was checked separately.

Public rule/route sources and review boundaries appear in the guidance modules and implementation report. Official institution forms retain their original language. Supported text and voice coverage remain separate; the five text-only languages are never given a working-voice claim. Synthetic audio is built only from the exact committed public corpus, with model/text/file hashes and unsupported-symbol checks. Private entries are not included in this corpus.

The second plain-language pass shortened primary screens and moved necessary detail into optional explanations. Fifty obsolete guidance strings and four unused support labels were removed after branch-render coverage checks. Hindi/Urdu nomination-versus-naming ambiguities were corrected; matching recordings were regenerated. All twenty regional packs remain draft translations.
