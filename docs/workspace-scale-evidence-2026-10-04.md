# Synthetic 50-account encrypted workspace evidence — 4 October 2026

The supported maximum of 50 accounts previously had no explicit encrypted workspace regression. The current public data path now has two additional tests, bringing the complete rebuilt release gate to **104 passing tests**. [Release output](audits/2026-10-04-workspace-scale/release-check.txt) and [measurement](audits/2026-10-04-workspace-scale/measurement.json) are retained. No runtime or published asset changed.

The fictional fixture contains 50 distinct accounts across bank/demat/mutual-fund types, 20 events per account, native-script private notes, an unfinished Urdu draft, and a separate confirmation editor with partial digits/date fields. Authenticated encryption followed by decryption and normal workspace validation produces the exact validated original, retaining all records, draft and editor state. A 51st record is rejected. Truncated envelope JSON, truncated ciphertext, authenticated plaintext with an invalid language, and authenticated plaintext with a duplicate account are rejected by the appropriate envelope/authentication/schema checks. These tests exercise the current public functions; they do not execute file-picker or device-storage UI, nor demonstrate that a browser preserves live state after a failed import.

The plaintext fixture is **74,300 bytes**; each encrypted envelope is **99,251 bytes**. Three sequential runs on this desktop host using Node v26.0.0 WebCrypto (macOS arm64) measured sealing at **68.455–74.112 ms**, unlocking at **70.761–72.673 ms**, and workspace validation at **1.168–1.367 ms**. There is no timing pass threshold and these are not mobile browser latency or physical 2 GB Android results. The measurement records exact SHA-256 hashes of the four public data-path modules. Reproduce from the repository root with `node app/scripts/workspace-scale-audit.mjs OUTPUT_JSON`.

Earlier navigation measurements remain attached to their frozen manifests. The recent audio-focus fix changes control focus restoration, while the preceding combobox/credit-label changes affect interaction/copy. None supplies a new startup performance hypothesis warranting another identical navigation run in this bounded audit. No historical timing is relabeled as a measurement of the current manifest. A new physical-device or defined user-task measurement would add evidence that navigation-only desktop repetition cannot supply.

Still required: actual save/download/file-import/unlock interaction and wrong-password/corrupt-file recovery; an in-progress draft across a real update; physical 2 GB Android with 50 accounts, native IME, on-screen keyboard, TalkBack, storage denial/eviction, tab termination and repeated outages; fluent whole-journey text/listening review; representative target-user task outcomes and a defined traffic-capacity exercise; viable lawful voices for the five text-only languages. Existing deterministic recovery/cache coverage and this desktop crypto measurement do not close those gates.
